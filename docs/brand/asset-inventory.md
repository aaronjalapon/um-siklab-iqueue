# TripSync Approved Brand Assets

All paths are repository-relative. Do not create alternate marks from screenshots or AI-generated approximations.

| Asset | Path | Approved use |
| --- | --- | --- |
| Full-color vector mark | `frontend/public/logo.svg` | Scalable web, documents, and export source |
| Full-color raster mark | `frontend/public/tripsync-mark.png` | Product header lockups and previews |
| Navy monochrome mark | `frontend/public/brand/tripsync-mark-navy.svg` | Light neutral backgrounds |
| White monochrome mark | `frontend/public/brand/tripsync-mark-white.svg` | Civic Navy and dark backgrounds |
| Apple touch icon | `frontend/public/icons/tripsync-apple-touch-icon.png` | iOS home screen |
| PWA icons | `frontend/public/icons/tripsync-icon-192.png`, `tripsync-icon-512.png` | Installed app icons |
| Maskable PWA icons | `frontend/public/icons/tripsync-maskable-192.png`, `tripsync-maskable-512.png` | Android adaptive masks |

## Usage rules

- Preserve aspect ratio and intrinsic padding.
- Use at least 24px for the mark and 96px for the mark-and-wordmark lockup.
- Reserve clear space equal to half the rendered mark height.
- The `BrandLogo` product component is the canonical digital horizontal lockup.
- Do not apply shadows, outlines, gradients, rotations, or unapproved colors.
- Archive replaced assets rather than silently overwriting the approved source.
